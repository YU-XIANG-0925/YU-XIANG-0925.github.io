# 3D 機器人動作展示專案 (重現與解密)

本專案旨在重現 Nuwa Robotics 的線上 3D 機器人展示頁面 (`https://dss.nuwarobotics.com/static/robot/robot.html`)，並對其動作檔案的載入機制進行修改與分析。

## 專案核心

此專案的核心改動在於：

1.  **本地化動作檔案**: 將原先需要從遠端伺服器載入的加密動作檔案，下載至本地的 `static/robot/motions/` 目錄中。
2.  **逆向解密**: 根據原專案使用的 `crypto-js` 函式庫，分析其加密邏輯，並編寫了 `decrypt_motion.js` 腳本，將加密的動作檔案批次解密為可讀的明文 XML 格式。
3.  **修改載入邏輯**: 調整原始的 JavaScript 程式碼，使專案能夠直接讀取並播放這些本地的、未加密的 XML 動作檔案，從而擺脫對遠端伺服器的依賴。

## 功能

*   **基於 Nuwa 機器人展示的重現**: 在本地環境重現了官方的 3D 機器人模型與動作展示功能。
*   **離線動作播放**: 所有的機器人動作檔案都儲存在本地，可以在沒有網路連線的情況下運作。
*   **開放的動作檔案**: 動作檔案以明文 XML 的形式存在，方便後續的分析、修改或擴充。

## 技術棧

*   **前端**: HTML, CSS, JavaScript
*   **3D 渲染**: [Three.js](https://threejs.org/)
*   **輔助函式庫**:
    *   [jQuery](https://jquery.com/): 用於簡化 DOM 操作和事件處理。
    *   [Bootstrap](https://getbootstrap.com/): 用於快速建構響應式佈局和 UI 元件。
    *   [CryptoJS](https://github.com/brix/crypto-js): 原專案用於加密動作檔案的函式庫，本專案則利用其進行反向解密。

## 專案結構

*   `static/`: 存放重現後的前端應用程式。
    *   `robot.html`: 專案的主要進入點。
    *   `robot/motions/`: 存放從官方伺服器下載並已解密的明文 `.xml` 動作檔案。
*   `decrypt_motion.js`: 用於將加密動作檔解密為明文 XML 的 Node.js 腳本。
*   `encrypt_motion.js`: (可選) 用於將明文 XML 加密回原格式的腳本。
*   `decrypted_motions/`: 存放解密後的 XML 檔案備份。
